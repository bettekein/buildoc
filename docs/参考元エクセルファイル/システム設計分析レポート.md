## 4. 実装優先順位の提案

### Phase 1: 高優先度（グリーンファイル基盤強化）
1. **Staff マスター拡張**
   - 健康診断受診日
   - 送り出し教育受講日
   - 資格詳細（取得日、有効期限）

2. **新規入場者調査票の実装**
   - 作業員名簿と連動
   - 入場時に自動生成可能

3. **社会保険加入状況帳票の実装**
   - 既存データから出力

### Phase 2: 中優先度（施工体制台帳）
1. **下請業者（Subcontractor）テーブル新規作成**
   - 一次～三次下請まで対応
   - 建設業許可情報の管理

2. **施工体制台帳・下請編成表の実装**
   - プロジェクトに下請を紐付け

### Phase 3: 請求書機能強化
1. **Tenant情報の拡張**
   - インボイス登録番号
   - 銀行口座情報

2. **工種マスターの実装**
   - 見積・請求で統一利用

## 5. 次の開発アクション

上記分析に基づき、以下の順序で開発を進めることを推奨します：

1. **Staffマスターの情報拡充**（健診日、教育記録、資格詳細）
2. **新規入場者調査票（PDF/Excel）の出力機能**
3. **社会保険加入状況帳票の出力機能**
4. **下請業者管理テーブルの新規作成**
5. **施工体制台帳の出力機能**
